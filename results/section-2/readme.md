# 📊 Row-level performance data

The performance rows behind the BERT-family share and the Δ synthesis in Section 4.3.2 of the review.

| File | Contents |
|---|---|
| `Row_level_performance_data.docx` | All 133 rows, grouped by text length |
| `bert_family_share_rows.csv` | The same rows, machine-readable |

**One row** = one study × one dataset × one metric. A row is **counted** when at least two systems are compared and at least one is a BERT-family model. Scores are taken as reported in the original papers.

These are descriptive counts, not a meta-analysis (see Section 2.6).
